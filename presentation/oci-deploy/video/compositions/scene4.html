Caddyfile (live.duse.dev)
live.duse.dev {
  handle /api/internal/* {
    respond 404
  }
  handle /api/* {
    reverse_proxy 127.0.0.1:8180
  }
  handle /media/* {
    reverse_proxy 127.0.0.1:8180
  }
  handle_path /hls/* {
    reverse_proxy 127.0.0.1:8888 {
      header_down Location ^/ /hls/
    }
  }
  handle_path /whip/* {
    reverse_proxy 127.0.0.1:8889
  }
  handle {
    root * /var/www/live.duse.dev
    try_files {path} /index.html
    file_server
  }
}

왜 127.0.0.1에 묶나
Docker가 연 포트는 iptables INPUT 규칙을 우회한다.
127.0.0.1에 묶어야 Caddy를 거쳐서만 들어온다.
