# Web Broadcast 발표 영상 리뷰

검토본은 `presentation/web-broadcast-presentation.mp4` (7분 05.57초, 1920×1080, 30fps)입니다. 포트폴리오를 처음 보는 개발자를 기준으로 14개 장면의 시작·중간·끝과 주요 프레임을 확인했습니다. 자막과 기술 설명은 대본, 캡처·합성 스크립트, 앱 구현과 대조했습니다. 음성은 파형에서 음량과 무음 구간을 측정했습니다. 발음 청취와 앱 동작 재실행은 검토 범위에서 제외했습니다. 아래 시각은 현재 MP4 기준입니다.

방송자와 시청자로 나눈 구성, 일관된 색상, 읽기 쉬운 하단 자막은 유지할 만합니다. 발표에서 가장 설득력 있는 부분은 라이브 상태 동기화와 결제 타임아웃 처리입니다. 각 장면에서 사용자가 무엇을 했고 어떤 결과가 생겼는지 먼저 보여주면 두 설계가 필요한 이유도 더 잘 전달됩니다.

## P1 · 공개 전에 수정

### 1. 05:02–06:20 · 결제창, 승인 로직, 후원 알림의 증거를 구분

- **관찰** — 테스트 결제창 뒤에 승인 로직과 5,000원 알림이 연속해서 나와 한 건의 결제를 처음부터 끝까지 완료한 것처럼 보입니다. 캡처 스크립트는 대기 후원을 DB에서 직접 `DONE`으로 바꿉니다. 06:08 프레임의 왼쪽은 시청자 후원 기록, 오른쪽은 방송자 팝업입니다. [캡처 절차](tools/capture/live.mjs) · [데모 데이터 설명](README.md)
- **수정** — 장면 10에 `토스페이먼츠 테스트 결제창`, 장면 11에 `서버 승인 로직`, 장면 12 전체에 `알림 UI 데모 · 완료 처리한 샘플 후원`을 표시합니다. 장면 12 첫 문장은 “완료 처리한 샘플 후원으로 시청자 화면의 기록과 방송자 화면의 알림을 보여드립니다”로 교체합니다. 양쪽 카드에 `시청자 · 후원 기록`과 `방송자 · 후원 알림` 라벨을 붙이고 5,000원 카드를 확대합니다. 타이밍 설명은 “방송 중에는 완료된 후원을 3초 주기로 조회합니다”로 바꿉니다. 팝업 등장 자체를 보여주려면 두 화면을 미리 열어 두고 새 완료 후원이 반영되는 순간을 녹화합니다. [후원 조회 훅](../web/src/live/useBroadcastDonations.ts)
- **완료 기준** — 화면과 나레이션만으로 테스트 결제창과 샘플 데이터 알림을 구분할 수 있습니다. 3초는 조회 주기로 전달합니다.

### 2. 03:47–04:17 · 비로그인 시청을 실제 화면으로 보여주고 설명 정정

- **관찰** — 04:06에는 `로그인 없이 누구나` 카드와 로그인된 `데모시청자 / 로그아웃` 화면이 함께 나옵니다. 라이브 페이지에는 최근 종료 방송도 별도 섹션으로 나옵니다. MediaMTX의 `read` 훅은 종료된 방송을 제외하고, 웹 플레이어는 `LIVE` 상태에서만 재생 URL을 사용합니다. [캡처 스크립트](tools/capture/live.mjs) · [라이브 목록](../web/src/pages/LiveListPage.tsx) · [시청 권한](../server/src/main/java/com/webbroadcast/broadcast/BroadcastService.java) · [시청 페이지](../web/src/pages/LiveWatchPage.tsx)
- **수정** — 장면 7 목록과 재생은 새 비로그인 브라우저 컨텍스트에서 캡처합니다. 댓글과 후원은 기존 로그인 컨텍스트를 사용합니다. “라이브 섹션에는 방송 중인 방송이 표시되고, 종료된 방송은 별도 섹션에 표시됩니다”라고 설명합니다. 훅을 다룰 때는 “미디어 서버는 종료된 방송의 읽기 요청을 거부하고, 웹은 방송 중일 때 재생 화면을 엽니다”로 역할을 나눕니다. `2~4초`는 이번 캡처에서 측정한 값처럼 보이지 않도록 데모 조건에서 측정 근거를 넣거나 수치를 덜어냅니다.
- **완료 기준** — 로그인 메뉴가 보이는 상태에서 라이브 카드 클릭과 재생 시작이 이어집니다. 목록과 인증 설명이 실제 구현과 일치합니다.

### 3. 03:08–03:47 · 업로드 완료를 보여주고 HLS 도식 정정

- **관찰** — 03:27 프레임은 처리 중 화면에서 멈춰 있고 장면 끝까지 공개 상태로 바뀌지 않습니다. 도식은 `ffmpeg 1회 실행 → 1080p/720p/480p + 썸네일`로 읽힙니다. 구현은 원본의 짧은 변에 맞는 화질을 골라 HLS를 한 번에 변환하고, 썸네일은 별도 ffmpeg 실행으로 만듭니다. [장면 생성기](tools/build_composition.py) · [화질 선택 규칙](../server/src/main/java/com/webbroadcast/media/Rendition.java) · [변환 구현](../server/src/main/java/com/webbroadcast/media/FfmpegVideoTranscoder.java)
- **수정** — 같은 동영상에서 `업로드 → 처리 중 → 공개·재생`을 보여줍니다. 대기 시간을 편집하면 `변환 완료 후`라고 표시합니다. 도식은 `원본 → 원본 해상도에 맞는 HLS 화질 생성`과 `원본 → 썸네일 추출`로 나눕니다. 1080p·720p·480p는 지원 화질 예시로 표기합니다. “재시작하면 남은 작업을 이어서 처리”는 “재시작하면 처리 중이던 항목을 다시 큐에 넣습니다”로 바꿉니다. [처리 큐](../server/src/main/java/com/webbroadcast/video/VideoProcessingQueue.java)
- **완료 기준** — 장면 6만 봐도 업로드가 완료됐음을 알 수 있고, HLS와 썸네일의 처리 방식이 구분됩니다.

### 4. 05:23–06:04 · 오래된 결제 대기의 처리 조건을 구분

- **관찰** — 영상은 30분이 지난 결제 대기를 모두 토스에 조회한 뒤 결과를 맞추거나 만료하는 것처럼 설명합니다. 구현은 승인 요청 기록이 없으면 만료시키고, 기록이 있으면 주문번호로 결과를 조회합니다. 조회 결과를 확인할 수 없는 예외 상황에서는 대기를 유지합니다. [결제 서비스](../server/src/main/java/com/webbroadcast/donation/DonationService.java)
- **수정** — 정리 작업 카드를 `30분 경과 → 승인 요청 전: 만료 / 승인 요청 후: 주문번호로 조회`로 바꿉니다. 앞부분은 `저장 금액 검증 → 같은 주문번호의 멱등키로 승인 요청 → 타임아웃 시 결제 대기 유지` 순서로 강조합니다. 화면의 코드는 해당 흐름을 보여주는 몇 줄만 남기고, 여러 메서드나 클래스를 합친 발췌본에는 `핵심 로직 요약`을 붙입니다.
- **완료 기준** — 만료 조건과 토스 조회 조건을 한눈에 구분할 수 있습니다.

## P3 · 편집 리듬

FFmpeg에서 −45 dB 기준으로 장면 전환 13곳에 각각 약 2.66~2.70초의 무음을 확인했습니다. 예를 들어 첫 전환은 00:25.33–00:28.00입니다. 장면 앞뒤 여백과 TTS 파일의 무음이 누적되는지 확인한 뒤 일반 전환을 먼저 줄이고, 방송자에서 시청자로 넘어가는 구간에는 호흡을 둡니다. 현재 통합 음량은 −14.1 LUFS, 트루피크는 약 −2.9 dBTP입니다. 재렌더 후에는 영어 기술명 발음과 자막 경계를 직접 확인합니다. [나레이션 생성기](tools/build_narration.py)

## Claude Code에 붙여넣을 요청

> `presentation/REVIEW.md`를 기준으로 발표 영상을 수정해줘. P1의 설명 정확성과 데모 표기를 먼저 고치고, P2의 오프닝·상태 전환·핵심 조작 컷을 반영해줘. 발표 영상의 대본, 캡처, 합성 소스에서 수정해줘. 장면 문장을 바꾸면 `build_composition.py`의 `sentence_starts()`와 `S[n]` 타이밍 참조도 맞춰줘. `presentation/README.md`의 절차에 따라 음성·타임라인·컴포지션을 다시 만들고, `presentation/video`에서 `npm run check`를 실행한 뒤 원본과 비교할 수 있게 `presentation/web-broadcast-presentation-v2.mp4`로 렌더해줘. 새 MP4에서 비로그인 시청, 업로드 공개, 후원 데모 라벨, 결제 대기 분기를 프레임과 음성으로 확인하고 수정된 타임스탬프와 검사 결과를 알려줘.
