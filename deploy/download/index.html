설치 방법

Windows에 설치하기
  1. 내려받은 WebBroadcast-windows-x64.msi를 실행합니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 설치 안내에 따라 다음을 눌러 설치를 마칩니다.
  4. 시작 메뉴에서 WebBroadcast를 검색해 실행합니다.

앱 화면은 Microsoft Edge WebView2로 표시됩니다. Windows 10·11에는 기본으로 들어 있습니다.

macOS에 설치하기
  1. 내려받은 WebBroadcast-macos-arm64.dmg를 엽니다.
  2. 앱 아이콘을 응용 프로그램 폴더로 끌어다 놓습니다.
  3. 응용 프로그램 폴더에서 앱을 엽니다. 처음 열 때 확인되지 않은 개발자라는 안내가 뜨면 완료를 누릅니다.
  4. 시스템 설정 → 개인정보 보호 및 보안으로 가서 아래쪽의 그래도 열기를 누른 뒤 다시 엽니다.

"손상되었기 때문에 열 수 없습니다"라는 안내가 뜨면 터미널에서 다음 명령을 실행한 뒤 다시 열어 주세요.
xattr -dr com.apple.quarantine /Applications/WebBroadcastApp.app
