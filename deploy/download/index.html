Web Broadcast 데스크톱 앱

live.duse.dev의 라이브 방송과 동영상을 데스크톱 앱으로 봅니다. 앱은 이 서버(https://live.duse.dev)에 연결되도록 빌드되어 있습니다.

Windows

Windows 10·11 · x64 (64비트 Intel/AMD) · 설치 파일 .msi

Windows용 다운로드

설치와 실행

  1. WebBroadcast-windows-x64.msi를 실행합니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다 (코드 서명을 하지 않은 앱이라 뜹니다).
  3. 설치 마법사를 끝까지 진행합니다.
  4. 시작 메뉴에서 WebBroadcast로 검색해 앱을 엽니다.

화면은 Microsoft Edge WebView2로 그립니다. Windows 10·11에는 기본으로 들어 있습니다.

macOS

macOS 11 이상 · Apple Silicon (arm64, M1 이후) · 디스크 이미지 .dmg

macOS용 다운로드

설치와 실행

  1. WebBroadcast-macos-arm64.dmg를 열고 앱을 응용 프로그램 폴더로 끌어 놓습니다.
  2. 응용 프로그램 폴더에서 앱을 엽니다. Apple 공증을 받지 않은 앱이라 처음에는 열리지 않고 경고가 뜹니다.
  3. 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기를 누르고 다시 엽니다.
  4. "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 아래 명령을 실행한 뒤 다시 엽니다.
    xattr -dr com.apple.quarantine /Applications/WebBroadcastApp.app

앱에서 확인할 것

화면확인 방법
라이브 목록앱을 열면 첫 화면에 방송 중인 방송과 최근 종료된 방송이 보입니다.
라이브 재생방송 중인 방송을 누르면 영상이 재생됩니다. 방송이 없으면 웹(live.duse.dev/broadcast)에서 하나 시작합니다.
동영상 재생머리글의 동영상 목록에서 영상을 누르면 재생됩니다.
