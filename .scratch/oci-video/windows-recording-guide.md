# Windows 앱 실행 녹화 안내

설명 영상([spec.md](spec.md)) 장면 6의 Windows 자리에 넣을 녹화본을 만드는 순서예요.
녹화본을 `presentation/oci-deploy/video/assets/media/windows-run.mp4`로 넣고 다시 렌더하면 장면 6·7이 바뀌어요. 렌더는 모든 수정이 끝난 뒤 한 번에 해요.

## 준비물

- Windows 10 또는 11 PC (x64). Windows 11에는 앱이 쓰는 WebView2가 이미 들어 있어요.
- GitHub 로그인 (새 설치 파일을 받을 때만 필요)
- 녹화 파일을 Mac으로 옮길 방법 (USB, 클라우드 드라이브 등)

로그인은 하지 않아요. 시청만 녹화하면 되고, 비밀번호 장면이 생기지 않게 하려는 거예요.

## 1. 설치 파일 받기 (녹화하지 않아도 돼요)

**새 빌드를 받아 주세요.** 이 빌드에는 2026-11-23 수정이 들어 있어요(메뉴 막대 제거, 방송 화면의 카메라·화면 공유). 다운로드 페이지의 파일(`desktop-v0.1.3`)에는 이 수정이 없어요.

1. Windows PC에서 GitHub에 로그인한 상태로 https://github.com/wiwi-git/web-broadcast-proj/actions/runs/45114790629 를 엽니다.
2. 아래쪽 **Artifacts**에서 `WebBroadcast-windows-x64.msi`를 누르면 zip 파일로 받아져요. 압축을 풉니다.
3. 예전 버전이 깔려 있으면 **설정 → 앱 → 설치된 앱**에서 지웁니다.
4. `.msi`를 실행해 설치합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 앱에 코드 서명이 없어서 뜨는 경고예요.
5. 설치가 끝나면 시작 메뉴에 **WebBroadcast**가 생겨요.

설치하다 막히면 그 화면을 캡처해서 알려 주세요.

## 2. 녹화 전에 할 일

1. **알림 끄기**: 설정 → 시스템 → 알림에서 "방해 금지"를 켭니다.
2. **데모 방송 켜기 (Mac)**: Mac 터미널에서 아래 명령을 실행하고, 데모방송 계정으로 로그인합니다.
   ```bash
   sh presentation/oci-deploy/tools/demo-broadcast.sh
   ```
   그다음 **방송 시작 → 종료 → 다시 시작**을 해 주세요. 가짜 카메라는 첫 방송에서 소리만 나가요. 두 번째 방송이 켜지면 녹화를 시작합니다.

## 3. 녹화

**녹화 도구**는 Xbox Game Bar예요. 선택한 **앱 창만** 녹화돼서 바탕화면과 작업 표시줄이 찍히지 않아요.

- 시작: 앱 창을 클릭한 뒤 `Win + Alt + R`
- 끝: 다시 `Win + Alt + R`
- 파일 위치: `동영상\캡처` 폴더 (mp4)

아래 순서로 **한 번에 이어서** 녹화해 주세요. 30~40초면 충분해요. 동작 사이에는 1~2초씩 멈춰 주세요.

| 순서 | 동작 | 길이 |
| --- | --- | --- |
| 1 | WebBroadcast 실행. 첫 화면(라이브 목록)과 맨 위에 **메뉴 막대가 없는 모습** | 5초 |
| 2 | 라이브 목록에서 **"데모 촬영용 방송"**을 눌러 재생 | 10초 |
| 3 | 상단 **동영상** 탭으로 이동해 **"데모 동영상 1"** 재생 | 10초 |

녹화가 끝나면 Mac의 방송 화면에서 "방송 종료"를 누르고 창을 닫아 주세요.

## 4. 함께 확인할 것

녹화와 별도로 확인해서 알려 주세요. 결과는 README에 기록해요.

- [ ] 설치가 됐다 (파란 경고 창이 떴는지도)
- [ ] 앱 위쪽에 Window·Edit 메뉴 막대가 **없다**
- [ ] 라이브가 재생된다 (영상과 소리)
- [ ] 동영상이 재생된다
- [ ] (선택, 녹화 안 함) 앱에서 로그인 → **방송하기** 화면에 카메라 미리보기와 화면 방송 선택지가 보인다
- Windows 버전 (설정 → 시스템 → 정보의 "에디션"과 "버전")
