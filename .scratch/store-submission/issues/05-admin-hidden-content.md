# 05. 운영자 화면에서 내린 콘텐츠 확인하기

Status: resolved (2026-11-27, 브랜치 `content-report`, 아직 커밋 전)

02(운영자 조치)를 보완한 편이다. 나중에 영상으로 만들 때 이 문서를 대본 재료로 쓴다.

## 한 줄 요약

운영자 화면에 **내린 콘텐츠** 탭을 추가했다. 운영자가 내린 동영상, 방송, 댓글을 종류별로 보고, 왜 내렸는지(신고)를 확인하고, **내린 동영상은 그 자리에서 재생**할 수 있다.

## 왜 만들었나

- 02에서 "내리기"는 지우지 않고 숨기는 방식으로 만들었다. 증거를 남기려는 것이다. 그런데 숨긴 콘텐츠는 운영자에게도 404라서, 남겨 둔 기록을 화면에서 볼 방법이 없었다.
- 사용자와 내린 동영상의 처리를 이야기한 결과(2026-11-27):
  - 파일과 업로드 용량은 **그대로 둔다**. 숨긴 동영상도 올린 사람의 2GB 한도에 계속 포함된다.
  - 대신 **운영자 화면에서 확인할 수 있게** 한다.
  - 댓글은 **운영자가 내린 댓글만** 볼 수 있게 한다. 작성자가 직접 지운 댓글은 지금처럼 완전히 지운다.

## 정한 규칙

| 항목 | 결정 |
|---|---|
| 보는 사람 | 운영자만(`/api/admin/**`) |
| 나누는 법 | 동영상 / 방송 / 댓글 종류 버튼. 처음에는 동영상 |
| 정렬 | 최근에 내린 순, 20개씩 |
| 보여 주는 것 | 내린 시각, 상태(변환 완료·방송 종료 등), 제목이나 댓글 본문, 올린 사람(정지 여부), 만든 시각, **내리게 만든 신고**(사유별 건수, 펼치면 신고자·사유·메모) |
| 동영상 | 썸네일, **영상 재생** 버튼(운영자 화면 안에서 HLS로 재생). 변환이 끝나지 않았으면 재생할 수 없다고 안내 |
| 댓글 | "달린 동영상(방송) 보기" 링크. 달린 곳도 내려졌으면 그 화면은 404 |
| 되돌리기 | 이번에는 만들지 않음 |

## 서버

### API

`GET /api/admin/hidden?type=VIDEO|BROADCAST|COMMENT&page=0` (운영자만)

```json
{
  "items": [{
    "type": "VIDEO", "id": "…", "summary": "댓글 숨김 확인 영상",
    "parentType": "VIDEO", "parentId": "…",
    "owner": { "id": "…", "nickname": "방송자74405", "suspended": false },
    "createdAt": "…", "hiddenAt": "…", "status": "PUBLISHED",
    "reportCount": 1, "reasons": { "COPYRIGHT": 1 },
    "reports": [{ "reporterNickname": "시청자74405", "reason": "COPYRIGHT", "detail": "다른 채널 영상을 그대로 올렸어요", "createdAt": "…" }],
    "playbackUrl": "/media/videos/…/master.m3u8", "thumbnailUrl": "/media/videos/…/thumbnail.jpg"
  }],
  "page": 0, "totalPages": 1, "totalItems": 2
}
```

- `reports`는 그 대상을 내릴 때 닫힌(`ACTIONED`) 신고다.
- `playbackUrl`과 `thumbnailUrl`은 변환이 끝난(공개 상태) 동영상만 있다. 파일이 디스크에 그대로 남아 있어서 재생된다.

### 코드

- `Broadcast`·`Video`·`Comment`: `getHiddenAt()`
- 각 Repository의 `findByHiddenAtIsNotNull(Pageable)`: 올린 사람이나 작성자를 함께 읽는다.
- 각 Service의 `listHidden(Pageable)`
- `ReportRepository.findByTargetTypeAndTargetIdInAndStatus`, `ReportService.actionedFor()`: 한 쪽의 대상들에 걸린 처리된 신고를 한 번에 읽는다(N+1 방지).
- `ModerationService.hidden(type, page)`, `HiddenContent`
- `ModerationController`: `GET /api/admin/hidden`, `HiddenItemResponse`. 사유 집계는 신고 카드와 함께 `countReasons()`로 쓴다.
- `VideoResponse.from()`을 공개해서 재생 주소를 만드는 규칙을 한 곳에 둔다.

### 테스트: `ModerationTest.adminsSeeHiddenContentWithWhyItWasHidden`

1. 동영상 하나(신고 2건, 저작권), 그 동영상의 댓글 하나(신고 1건, 욕설·혐오), 방송 하나를 내린다.
2. 일반 회원은 403이다.
3. 동영상 목록: 맨 앞이 그 동영상이고, 제목, 올린 사람, 내린 시각, 신고 2건, 저작권 2가 나온다.
4. 댓글 목록: 본문, 달린 동영상, 욕설·혐오 1이 나온다.
5. 방송 목록: 신고 없이 내린 방송도 나온다(신고 0건).

## 확인한 것 (2026-11-27, 로컬)

1. 시청자 계정으로 04에서 올린 시험 영상을 "저작권 침해, 다른 채널 영상을 그대로 올렸어요"로 신고하고, 운영자 세션(터미널)에서 내렸다. 일반 상세 조회는 404였다.
2. 운영자 화면 → 내린 콘텐츠 → 동영상: 2개가 보였다. 하나는 방금 내린 영상이고, 다른 하나는 같은 날 18:18에 운영 화면에서 내려진 "아이폰앱 영상 압로드 테스트"였다. 둘 다 썸네일, "변환 완료", 신고 요약이 있었다.
3. "영상 재생"을 누르자 내린 영상이 운영자 화면 안에서 재생됐다(2.1초 영상의 1.97초까지 재생 확인).
4. 신고 요약을 펼치자 "시청자74405 · 저작권 침해 · 다른 채널 영상을 그대로 올렸어요"가 보였다.
5. 댓글 종류로 바꾸자 그날 내린 댓글 3개가 나왔다. 신고 없이 내린 댓글 1개는 "남아 있는 신고 기록이 없습니다."로 나왔다.
6. 방송 종류는 비어 있었다. 이날 방송은 정지로 끝났을 뿐 내린 적은 없어서 맞는 결과다.

**아직 확인하지 않은 것**
- 내린 방송 카드를 화면에서 보는 것(테스트로만 확인)
- 휴대폰 폭 화면, 21개가 넘을 때의 쪽 이동

## 한계

- 되돌리기(숨김 해제)는 없다.
- 내린 동영상도 올린 사람의 업로드 용량에 계속 포함된다(사용자 결정). 올린 사람은 그 동영상을 지울 수도 없다.
- 댓글이 달린 동영상이나 방송까지 내려졌으면, "달린 곳 보기" 링크는 운영자에게도 404다.
- 작성자가 직접 지운 댓글은 남지 않는다(사용자 결정).

## 영상 시나리오 메모

1. 질문: "내린 영상은 어디로 가나?" → 숨김이라 파일은 남는데, 운영자도 볼 수 없었다.
2. 결정: 파일과 용량은 그대로 두고, 운영자 화면에서 보게 한다. 댓글은 운영자가 내린 것만.
3. 시연: 내린 콘텐츠 탭 → 동영상 카드(썸네일, 내린 시각) → 영상 재생 → 신고 펼치기("왜 내렸나")
4. 종류 바꾸기: 댓글 → 본문과 달린 곳, 신고 없이 내린 경우의 표시
5. 정리: 숨김 = 사용자에게는 사라짐 + 운영자에게는 기록. 탭 세 개(신고 관리, 내린 콘텐츠, 회원 관리)로 운영 화면 완성
