# 13. 앱에서 테스트 결제(후원) 숨기기

Status: resolved (2026-11-27, 브랜치 `email-account`, 아직 커밋 전)

이메일 계정 묶음(08~13)의 마지막 편이다.

## 한 줄 요약

앱(Windows·macOS·모바일, Dioxus)에서 **"후원하기" 버튼과 계정 메뉴의 "후원 내역"을 숨겼다**. 웹에서는 그대로 쓸 수 있다.

## 왜

- 사용자 요청(2026-11-27): "테스트 결제 기능은 앱에서 가림(웹에서만 일단 남겨만둠)"
- 스토어 심사 관점
  - 실제로 돈이 오가지 않는 테스트 결제가 앱에 보이면 "동작하지 않는 기능"으로 보일 수 있다.
  - 디지털 콘텐츠 결제 정책(10.8)을 따져야 할 부분도 줄어든다.

## 정한 것 (사용자와 결정)

| 항목 | 결정 |
|---|---|
| 숨기는 것 | 방송 시청 화면의 "후원하기" 버튼, 계정 메뉴의 "후원 내역" |
| 그대로 두는 것 | 웹에서 보낸 후원이 방송 화면에 알림으로 뜨는 것 |
| 다시 켜기 | `app/src/config.rs`의 `SHOW_DONATIONS`를 `true`로 바꾸면 돌아온다 |

## 코드

- `app/src/config.rs`: `pub const SHOW_DONATIONS: bool = false;` 왜 숨기는지 주석을 달았다.
- `app/src/pages/live.rs`: `if live && !owned && config::SHOW_DONATIONS { 후원하기 }`
- `app/src/components/shell.rs`: 계정 메뉴의 "후원 내역" 링크를 같은 조건으로 감쌌다.
- 후원 화면 경로(`/live/:id/donate`, `/donations`)와 결제 딥링크 처리는 그대로 남겼다. 다시 켤 때 고칠 곳이 적다.
- 웹(React)은 바꾸지 않았다.

## 확인한 것 (2026-11-27, 로컬)

- 앱(Dioxus 웹 빌드, `dx serve --platform web`)의 계정 메뉴에 "내 계정", "로그아웃"만 있고 "후원 내역"은 없었다.
- **"후원하기" 버튼은 화면으로 확인하지 못했다.** 방송 중인 방송이 있어야 보이는 버튼이라, 코드의 조건만 확인했다. 앱 빌드와 clippy는 통과했다.

## 영상 시나리오 메모

1. 웹과 앱의 차이를 한 줄 설정으로 둔 이유
2. 방송 화면 나란히: 웹에는 후원하기, 앱에는 없음, 후원 알림은 둘 다 보임
