# 랜딩 페이지

Status: ready-for-agent

## 왜

과제로 랜딩 페이지를 만든다. 과제 조건(기술·형식·마감)은 따로 없다.
소개 대상은 live.duse.dev에서 돌아가는 방송 서비스 **Web Broadcast**다. 과제 평가자와 실제 방문자가 함께 본다. 그래서 실제로 배포할 수 있는 수준으로 만든다.

## 지금 상태 (2026-11-26 확인)

- live.duse.dev의 `/`는 React 앱의 라이브 목록(`LiveListPage`)이다. `web/src/App.tsx`
- `/download/`는 Caddy가 내보내는 고정 HTML 다운로드 페이지다. `deploy/download/index.html`
- duse.dev 첫 화면(`deploy/duse-dev/`)은 서비스 상태 페이지다. 이번 범위가 아니다.
- 서비스를 소개하는 페이지는 없다.
- 웹 앱에는 다크 모드가 없다. `web/index.html`에는 `description`과 `og:` 메타 태그가 없다.

## 결정

### 주소

- `/`가 랜딩이다. 로그인 여부와 상관없이 모두에게 같은 랜딩을 보여 준다.
- 라이브 목록은 `/live`로 옮긴다. `/live/:id`(시청)는 그대로 둔다.
- 라이브 목록을 뜻하던 `/` 링크를 `/live`로 바꾼다.
  - `App.tsx` 헤더의 "라이브" `NavLink`
  - `BroadcastPage.tsx:218`의 버튼
  - 로고 링크는 `/`(랜딩)로 둔다.

### 구현 방식

- `web/src/pages/LandingPage.tsx`와 랜딩 전용 CSS 파일을 새로 만든다. 기존 `index.css`는 건드리지 않는다.
- 새 라이브러리는 추가하지 않는다. 데이터는 `api.ts`의 `fetchBroadcasts`와 `fetchVideos`를 다시 쓴다.
- 랜딩에도 기존 앱 헤더를 그대로 보여 준다.
- 한국어로만 만든다. 서비스 이름은 "Web Broadcast"를 쓴다. 다른 실제 방송 서비스의 이름, 로고, 디자인은 쓰지 않는다.

### 섹션 (위에서 아래로)

1. **히어로**
   - 서비스 한 줄 소개
   - 주요 버튼 "지금 라이브 보기"(`/live`), 보조 버튼 "방송 시작하기"(`/broadcast`, 로그인하지 않았으면 기존 흐름대로 로그인으로)
   - 실제 데이터로 "지금 N개 방송 중"을 보여 준다.
2. **지금 방송 중**
   - 방송 중인 방송 카드 최대 4개. 누르면 `/live/:id`로 간다.
   - 방송이 없으면 "지금은 방송이 없어요"와 최근 동영상 카드를 보여 준다. 동영상 카드는 `/videos/:id`로 간다.
   - 불러오기 실패나 로딩 중에도 페이지의 나머지는 정상으로 보인다.
3. **기능 소개 3개**
   - 휴대폰 카메라로 바로 방송
   - 동영상 올리고 보기
   - 방송자에게 후원. "테스트 결제라 실제로 돈이 나가지 않음"을 꼭 적는다.
4. **데스크톱 앱**: Windows·macOS 앱 소개, `/download/` 링크
5. **푸터**: GitHub 저장소 링크

### 이미지

- 기능 소개에는 실제 서비스 스크린샷을 쓴다.
- 스크린샷은 직접 띄운 데모 방송(Chrome 가짜 카메라)과 데모 콘텐츠로만 찍는다. 다른 회원의 방송이나 닉네임이 찍히면 안 된다.
- 스크린샷이 준비되기 전에는 기존 아이콘 컴포넌트로 대신한다.

## 완성 기준

- [ ] `/`에서 랜딩이, `/live`에서 라이브 목록이 보인다. 헤더 "라이브" 링크와 방송 화면 버튼이 `/live`로 간다.
- [ ] 히어로의 방송 수와 "지금 방송 중" 카드가 실제 데이터와 맞는다. 방송이 없을 때 최근 동영상으로 대신한다.
- [ ] 휴대폰 너비(375px)부터 데스크톱까지 가로 스크롤이 생기지 않는다.
- [ ] `web/index.html`에 `description`과 `og:` 메타 태그(제목, 설명, 이미지)가 있어 링크 공유 시 미리보기가 나온다.
- [ ] 키보드만으로 모든 버튼과 링크에 갈 수 있고, 모든 이미지에 대체 텍스트가 있다.
- [ ] 다크 모드는 넣지 않는다. 앱 전체에 없어서다.
- [ ] `npm run build`와 `npm run lint`가 통과한다.
