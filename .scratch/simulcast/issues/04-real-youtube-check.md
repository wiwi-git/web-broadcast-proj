# 진짜 유튜브로 동시 송출 확인

Status: ready-for-human
Blocked by: 02, 03

유튜브 채널의 라이브 스트리밍 활성화 대기(24시간, 2026-11-19 신청)가 끝난 뒤 한다.

## 확인할 것
- [ ] 유튜브 스튜디오의 키를 등록하고 동시 송출을 켜면 유튜브 스튜디오에 방송이 들어온다
- [ ] 영상과 소리가 나오고, 유튜브 스튜디오 경고(키프레임 간격 등)를 적어 둔다
- [ ] 휴대폰 세로 방송이 유튜브에서 어떻게 보이는지
- [ ] 우리 방송을 끝내면 유튜브 쪽도 끝난다
- [ ] 키를 틀리게 넣으면 방송자 화면에 "실패"가 뜨고 우리 방송은 이어진다
