# iOS 앱(Dioxus) 실기기에서만 확인할 수 있는 것

Status: ready-for-human

04에서 기본 흐름(로그인, 시청, 업로드, 송출, 결제)은 확인했다. 여기는 그 뒤에 새로 만들었거나,
카메라·네트워크·전원·앱 전환처럼 시뮬레이터로는 확인할 수 없는 것들이다. 준비는 04와 같다 (`app/scripts/ios-device.sh`).

## 확인할 것

### 방송하기 (아이폰이 방송자)
- [x] 방송 중 카메라 아래에 시청자 댓글과 후원이 보인다 (2026-11-18)
- [x] 방송 중 후원이 들어오면 카메라 미리보기 위에 알림이 5초 동안 뜬다 (2026-11-18)
- [x] 미리보기에서 전면/후면 카메라 전환이 된다 (2026-11-18)
- [ ] ~~휴대폰을 가로로 들고 송출하면 시청 화면에도 가로로 나온다~~ 앱 화면이 가로로 돌지 않는다. 그대로 두기로 함 (2026-11-18)
- [x] 방송 중 화면이 저절로 꺼지지 않는다 (2026-11-18, 자동 잠금 시간이 지나도 켜져 있음 — 앱 WebView에서도 Wake Lock 동작)
- [x] 방송 중 홈으로 나갔다 돌아와도 송출이 이어진다 (2026-11-18)
- [x] 방송 중 화면을 잠그면 그동안 송출 화면이 멈추고, 잠금을 풀면 같은 방송으로 다시 이어진다 (2026-11-18). 잠근 동안 iOS가 카메라를 멈추는 것으로 보이며 방송은 종료되지 않는다
- [x] 방송 중 와이파이를 끄면 방송이 종료된다 (2026-11-18)

### 시청 (WebRTC, ADR-0006)
- [ ] 라이브에 들어가면 소리와 함께 바로 재생된다 (자동 재생이 막혀 소리 없이 시작하는지)
- [ ] 소리 품질: "음질이 나쁘다"는 의견이 있었다. 송출 쪽 마이크 설정(에코·소음 제거)과 Opus 비트레이트를 바꾸며 비교한다
- [ ] 지연이 1초 안쪽인지 (방송 화면 앞에 시계를 비춰 비교)
- [ ] 시청 중 와이파이가 잠깐 끊겼다 돌아오면 다시 이어서 재생된다
- [ ] 시청 중 앱을 백그라운드로 보냈다 돌아오면 다시 재생된다

### 업로드
- [ ] 수백 MB 영상도 끝까지 올라간다 (웹뷰에서 1MB씩 옮기는 단계의 시간과 메모리)
- [ ] 업로드 중 앱을 백그라운드로 보내면 어떻게 되는지
- [ ] 파일 선택에서 "동영상 촬영"으로 찍은 영상도 올라간다

### 후원·딥링크
- [ ] 앱을 완전히 종료한 상태에서 결제를 마치면 앱이 새로 켜지며 후원한 방송 화면으로 간다 (콜드 스타트 딥링크)
- [ ] 결제 앱(카카오페이 등)으로 갔다가 Safari로, 다시 앱으로 돌아오는 흐름

### 처음 설치·권한
- [ ] 앱을 지우고 새로 설치했을 때 "로컬 네트워크" 권한 요청이 뜨고, 허용 전후로 목록이 불러와진다
- [ ] 카메라·마이크 권한을 거부하면 방송하기에 안내 문구가 뜨고, 설정에서 허용하면 다시 된다
- [ ] 로그인 후 30분 동안 아무것도 안 하면 로그인이 풀리고(서버 세션 만료) 다시 로그인하면 된다

## 시뮬레이터로 확인할 수 있는 것 (실기기 불필요)

- 앱의 후원 화면에서 숫자 키패드가 후원하기 버튼을 가리는지. 웹은 iOS Safari에서 가려서 고쳤고(web/src/keyboardInset.ts), 앱은 같은 화면 구조라 같을 가능성이 높다.
