# 후원 결제 실기기 테스트

Status: ready-for-human

먼저 `server/config/local.properties`에 본인의 토스페이먼츠 API 개별 연동 테스트 키를 넣어야 한다(README "토스페이먼츠 키 넣기").

후원 단계는 데스크톱 브라우저에서 다음을 확인했다. 처음에는 결제위젯 문서용 키로 확인했고, 통합결제창으로 바꾼 뒤에는 결제창을 여는 단계까지만 확인했다.

- 결제위젯 표시
- 결제창을 닫아 취소하기
- 실제 토스페이먼츠 승인 API의 거절 응답
- 금액 위변조 차단
- 결과 화면, 알림, 후원 내역

결제를 끝까지 마치는 단계는 확인하지 못했다. 테스트 결제창이 카드사 앱, 토스 앱 QR, 카드번호 입력 같은 실제 인증을 요구하기 때문이다. 테스트 키라서 결제가 승인되어도 돈은 빠져나가지 않는다. 준비 방법은 `01-live-broadcast-on-real-phone.md`와 같다.

## 확인할 것

- [x] PC 브라우저에서 결제를 끝까지 마치면(예: 토스페이 → 휴대폰으로 QR 스캔) `/donations/success`로 돌아와 "후원했습니다"가 뜬다
- [ ] 그 결제가 개발자센터 [테스트 결제내역](https://developers.tosspayments.com/my/payment-logs)에 후원 금액·주문명("○○님에게 후원")으로 보인다
- [ ] 그 후원이 3초 안에 시청 화면 알림, 댓글 패널, 방송자 화면 알림으로 보이고, 후원 내역 두 탭에 나온다
- [ ] 휴대폰 브라우저(`https://<LAN_IP>:5173`)에서 후원하면 결제 앱으로 갔다가 돌아온 뒤에도 로그인이 유지되고 결과 화면이 뜬다
- [ ] 휴대폰에서 결제창을 닫거나 결제 앱에서 취소하면 `/donations/fail`로 돌아와 "후원을 취소했습니다"가 뜨고, 후원 내역에 취소로 남는다 (PC와 달리 휴대폰은 페이지 이동으로 돌아온다)
- [ ] 휴대폰 후원 화면에서 금액 입력칸을 누르면 숫자 키패드가 뜨고, 키보드가 결제 버튼을 가리지 않는다
- [ ] 방송자가 휴대폰으로 송출하는 중 후원이 들어오면 카메라 미리보기 위에 알림이 5초 동안 뜬다

## Comments

- 2026-11-09: 본인 API 개별 연동 테스트 키로 PC에서 1,000원 간편결제를 끝까지 마쳤다. 서버에 완료로 저장되었고, 토스페이먼츠 조회 API에서도 같은 orderId가 DONE·1,000원으로 확인되었다. 시청 화면 댓글 패널에 후원 메시지가 떴다(사용자 확인).
