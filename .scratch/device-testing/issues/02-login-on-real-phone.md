# 로그인·댓글 실기기 테스트

Status: ready-for-human

회원·댓글 단계는 데스크톱 브라우저에서만 확인했다. 휴대폰에서는 `https://<LAN_IP>:5173`(자체 서명 인증서)로 접속하므로 쿠키 동작이 다를 수 있다. 준비 방법은 `01-live-broadcast-on-real-phone.md`와 같다.

## 확인할 것

- [ ] iPhone Safari, Android Chrome에서 회원가입·로그인이 되고, 새로고침해도 로그인이 유지된다 (세션 쿠키)
- [ ] 로그인한 뒤 방송 시작·종료가 된다 (CSRF 토큰 쿠키가 HTTPS LAN 주소에서도 저장되는지)
- [ ] 로그인하지 않고 `/broadcast`에 들어가면 로그인 화면으로 갔다가, 로그인 후 방송 화면으로 돌아온다
- [ ] 휴대폰 시청 화면에서 댓글 입력칸을 누르면 키보드가 댓글 목록을 가리지 않는다
- [ ] 방송 중 다른 기기에서 쓴 댓글이 3초 안에 보인다
- [ ] 방송자가 휴대폰에서 방송하는 동안 PC에서 같은 계정으로 "방송 종료"를 누르면 휴대폰 화면도 종료로 바뀐다
