# iOS 앱(Dioxus) 실기기 테스트

Status: resolved

01~03은 휴대폰 **브라우저**로 웹을 쓰는 경우다. 이 이슈는 `app/`을 아이폰에 설치한 **앱**을 확인한다.

## 준비

1. Xcode에서 Bundle Identifier `com.webbroadcast.app`으로 빈 앱을 아이폰에 한 번 실행해 프로비저닝 프로파일을 만든다 (2026-11-18에 만듦, 2027-11-18 만료).
2. Docker를 켜고 MediaMTX가 휴대폰에 Mac 주소를 알리게 한다: `LAN_IP=<Mac LAN IP> docker compose up -d mediamtx`
3. 서버(`server`)와 같은 Wi-Fi에서 열리는 웹(`web-lan`, 결제 화면용)을 띄운다.
4. `app/scripts/ios-device.sh`로 Mac 주소를 넣어 빌드하고, 아이콘을 넣어 서명한 뒤 설치·실행한다.

## 확인할 것

- [x] 앱이 뜨고 라이브 목록이 나온다 (2026-11-18, iPhone SE)
- [x] 회원가입·로그인이 되고, 앱을 껐다 켜도 로그인이 유지된다 (2026-11-18)
- [x] 홈 화면에 파비콘 아이콘이 보인다 (2026-11-18)
- [x] 라이브 시청이 멈추지 않고 이어진다 (2026-11-18, WebRTC로 시청 — iOS는 Opus를 HLS로 못 풀어 ADR-0006. 음질이 나쁘다는 의견 있음)
- [x] 동영상(VOD)이 재생된다 (앱의 동영상은 네이티브 재생) (2026-11-18)
- [x] 업로드에서 파일 선택 창(사진 보관함)이 뜨고 업로드가 끝난다 (2026-11-18, 7.8초 영상이 변환까지 끝나 공개됨. Dioxus 파일 입력이 iOS에서 동작하지 않아 components/webview_file.rs로 우회)
- [x] 방송하기에서 카메라·마이크 권한 요청이 뜨고 미리보기가 나온다 (맥 앱에서는 카메라가 잡히지 않았다) (2026-11-18)
- [x] 방송 시작 후 PC 시청 화면에 영상이 나온다 (2026-11-18, 세로 440×782로 Mac 웹에서 재생)
- [x] 후원하기를 누르면 Safari에서 결제 화면이 열리고, 결제를 마치면 앱의 후원 내역으로 돌아온다 (딥링크 `webbroadcast://donations`) (2026-11-18, 1,000원 후원 완료)
- [x] 결제를 마치면 후원 내역 대신 후원한 방송 화면으로 돌아온다 (딥링크 `webbroadcast://live/{id}`로 바꿈) (2026-11-18)
- [x] 결제 화면에서 취소하고 "앱으로 돌아가기"를 누르면 앱으로 돌아온다 (2026-11-18, 후원은 결제 대기로 남음 — ADR-0005대로 만료 시간이 지나면 만료)

## Comments

2026-11-18, iPhone SE(iOS 26.6.2)에서 모든 항목을 확인했다. 테스트하며 고친 것:
- 라이브: iOS는 Opus 소리가 든 HLS를 풀지 못해 WebRTC(WHEP)로 본다 (ADR-0006).
- 업로드: Dioxus 파일 입력이 iOS에서 아무 창도 띄우지 않아 웹뷰 선택 창으로 우회했다 (`app/src/components/webview_file.rs`).
- 결제: 결제를 마치면 후원 내역 대신 후원한 방송 화면으로 돌아온다.
- 앱 아이콘: dx가 iOS 빌드에 넣지 않아 `app/scripts/ios-device.sh`가 넣는다.
남은 의견: WebRTC로 볼 때 음질이 나쁘다 (송출 쪽 마이크 설정·Opus 비트레이트를 볼 것).
